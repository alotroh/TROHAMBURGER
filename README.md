# TROHAMBURGER — сайт бургерной

Крафтовая смэш-бургерная. Тёмный характер, огонь, крупная типографика и
крутящийся бургер-фон, который поворачивается и приближается при прокрутке.

Собран на том же стеке, что и сайт салона красоты (Astro), — структуру взяли оттуда.

## Запуск

```bash
npm install
npm run dev      # локально на http://localhost:4330
npm run build    # прод-сборка в dist/
npm run preview  # посмотреть собранное
```

## Что где лежит

| Что менять | Файл |
|---|---|
| Название, адрес, телефон, часы, соцсети, навигация | `src/config/site.mjs` |
| Заголовки страниц для поиска (title/description) | `src/config/seo.mjs` |
| Меню, цены, состав, вес, метки | `src/data/menu.mjs` |
| Цвета, шрифты, кнопки, общий стиль | `src/styles/global.css` |
| Крутящийся бургер-фон и логика скролла | `src/components/BurgerStage.astro` |

Страницы: `src/pages/index.astro` (главная), `menu/`, `o-nas/`, `kontakty/`.

## Крутящийся бургер

Исходное фото — `media/бургер.png`. Оно было на чёрном фоне, поэтому фон
**вырезан** (прозрачный PNG `src/assets/media/burger-cut.png`) — бургер чисто
лежит на ровном плавном градиенте сцены, без прямоугольника и ореола. Логика
поворота и приближения — в `BurgerStage.astro`, в теге `<script>`: правится
одной строкой (коэффициенты `rot`, `scale`, `lift`; зум упирается в 1.5×).
Уважает «уменьшить движение» в системе.

## Корзина и заказы в Telegram

Витрина бургеров на главной — кликабельная: клик по карточке кладёт бургер в
корзину, кнопка **−** убирает. Внизу справа — плавающая корзина со списком,
итогом и формой оформления (имя, телефон, доставка/самовывоз, адрес, коммент).
Состояние живёт в `localStorage`.

**Чтобы заказы падали в Telegram**, впишите в `src/config/site.mjs`:

```js
export const TELEGRAM = {
  botToken: '123456:AA...',   // токен бота от @BotFather
  chatId: '123456789',        // id чата, куда слать заказы
};
```

Как узнать `chatId`: напишите своему боту любое сообщение и откройте
`https://api.telegram.org/bot<ТОКЕН>/getUpdates` — там будет `chat.id`.
Пока поля пустые — корзина работает в демо-режиме (показывает «заказ принят»,
но никуда не шлёт). Отправка идёт напрямую из браузера в Telegram Bot API;
для боевого сайта токен лучше прятать за своей серверной функцией.

## Фотографии

Все фото уже стоят. Их нарезали из трёх сгенерированных «листов» (`media/промпт
1..3.png`) и разложили по местам; карта импортов — `src/data/media.mjs`.
Чтобы заменить любое фото: положите новый файл в `src/assets/media/…`,
поправьте импорт в `media.mjs` — вёрстку трогать не нужно.

## Важно про концепт

Адрес, телефон, часы работы — заглушки (помечены в `site.mjs`). Меняются в одном
месте, когда появится реальная точка. Ни один факт не выдаётся за настоящий.
