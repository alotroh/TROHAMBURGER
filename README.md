# TROHAMBURGER — сайт бургерной

Крафтовая смэш-бургерная. Тёмный характер, огонь, крупная типографика и
крутящийся бургер-фон, который поворачивается и приближается при прокрутке.

Собран на том же стеке, что и сайт салона красоты (Astro), — структуру взяли оттуда.

## Запуск

```bash
npm install
npm run dev      # локально на http://localhost:4330
npm run build    # прод-сборка в dist/
npm run preview  # посмотреть собранное
```

## Что где лежит

| Что менять | Файл |
|---|---|
| Название, адрес, телефон, часы, соцсети, навигация | `src/config/site.mjs` |
| Заголовки страниц для поиска (title/description) | `src/config/seo.mjs` |
| Меню, цены, состав, вес, метки | `src/data/menu.mjs` |
| Цвета, шрифты, кнопки, общий стиль | `src/styles/global.css` |
| Крутящийся бургер-фон и логика скролла | `src/components/BurgerStage.astro` |

Страницы: `src/pages/index.astro` (главная), `menu/`, `o-nas/`, `kontakty/`.

## Крутящийся бургер

Фото бургера (`media/бургер.png`) лежит в `src/assets/media/burger-hero.png`.
Оно на чёрном фоне, поэтому вписано в тёмную сцену через `mix-blend-mode: screen`
+ радиальную маску (края растворяются). Логика поворота и приближения — в
`BurgerStage.astro`, в теге `<script>`: правится одной строкой (коэффициенты
`rot`, `scale`, `lift`). Уважает «уменьшить движение» в системе.

## Куда вставлять реальные фото

Сейчас на местах фото стоят **оформленные слоты** с подписью, что именно снять.
Как добавить настоящий снимок:

1. Положите файл в `src/assets/media/` (напр. `burger-troha-dabl.jpg`).
2. В нужном месте импортируйте его и передайте в `<PhotoSlot image={...} alt="…" />`
   (см. комментарий в `src/components/PhotoSlot.astro`) — инструкция-заглушка
   исчезнет, останется фото с плавным зумом при наведении.

### Список слотов

**Главная (`index.astro`)**
- 8 карточек бургеров — фото каждого бургера (подпись на карточке подсказывает ракурс).
- «Кухня в деле» — повар жмёт котлету на чугуне, вертикально.
- Галерея «Атмосфера»: Зал · Бургер крупно · Барная стойка · Команда у гриля · Картошка и соусы.

**Меню (`menu/index.astro`)**
- Фото-обложка к каждой категории: Бургеры · К бургеру · Соусы · Напитки.
- У каждой позиции есть подпись «📸 фото: …» — что снять на карточку в будущем.

**О нас (`o-nas/index.astro`)**
- «Тогда и сейчас» — архив/основатель у гриля.
- Кухня: Гриль · Сборка · Соусная.

**Контакты (`kontakty/index.astro`)**
- «Карта / фасад» — скрин карты с точкой или фото вывески.

## Важно про концепт

Адрес, телефон, часы работы — заглушки (помечены в `site.mjs`). Меняются в одном
месте, когда появится реальная точка. Ни один факт не выдаётся за настоящий.
